# SONAR Mobile App 📱🛒

A cross-platform **e-commerce mobile application** built using **Flutter** and **Firebase**, designed to offer a smooth and intuitive shopping experience on both Android and iOS platforms.

## 🔧 Features

* 🔁 **Onboarding Flow** – Introduces new users to key features of the app
* 🔐 **Authentication** – Secure sign-in and sign-up with Firebase Authentication
* 🏠 **Home Screen** – Displays popular and featured products with clean UI
* 🛍️ **Product Screen** – View detailed product info and pricing
* ➕ **Add to Cart** – Select products and manage cart contents
* 💖 **Wishlist Screen** – Save favorite items for later
* 👤 **Profile Management** – Edit account details, manage settings, and log out
* 🔥 **Responsive Design** – Optimized for Android and iOS devices
* 🔗 **Firebase Integration** – Real-time database & authentication support

## 🚀 Tech Stack

* **Flutter** – Cross-platform UI toolkit
* **Firebase** – Backend services (Authentication, Realtime Database)
* **Dart** – Programming language used for Flutter
* **Figma** – UI/UX design tool (for prototyping)
